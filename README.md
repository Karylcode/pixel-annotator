# 像素畫工具 — NEW UI（v2.0 桌面版 + 行動版）

依據 `UIUX修改設計文件.md` 實作的改版前端，2026-08-17 起為專案根目錄的正式版本（舊版前端整份保留在 `_舊版前端備份/`）。直接用瀏覽器開啟 `index.html` 即可（純靜態、無建置）；要在瀏覽器面板預覽可用 `.claude/launch.json`（`static`，port 8765）開 `/index.html`。

> 存檔：自 2026-08-17 起寫入 `localStorage` 鍵 `pixann.v2`（含版本、時間戳、RLE 壓縮的標註網格、每張圖的選取狀態）。第一次啟動若沒有 `pixann.v2` 會從舊版鍵 `pixann` 讀一次並遷移（舊鍵保留不動，`_舊版前端備份/` 裡的舊版仍可照常使用，兩者不再互相覆蓋）。配額不足時會保留上一份完整快照並在下次啟動時明確告知「還原的是較舊的版本」；另一個分頁保存了較新的資料時，這個分頁會暫停自動保存並提示。

## 與舊版的關係

- `js/codec.js`：文字 ⇄ 像素 ⇄ 匯出格式，錯誤訊息改全形標點；新增 `zip()`（純封裝、不壓縮，給「匯出全部」用，無外部依賴）。
- `js/pixelate.js`：沿用全部演算法，新增 `detectGridAsync()`（分段讓出主執行緒，支援進度條與取消）。
- `js/store.js`：復原堆疊改為 past / future（**Redo**）、每筆快照帶 label **並連部件清單與選取狀態一起存**（刪除部件 / 匯入標註 / 清空後復原，部件列會一起回來）、`undoOnce()/redoOnce()` 回報是否改了尺寸、`historyLabels()`、新部件**自動配色**、切換圖片記住各自的作用中部件、`save()` / `persist()` 回報配額失敗、點陣圖進 IndexedDB、新增 `coverage()` / `hasAnnotation()` / `soloShown()` / `selectionMask()`（魔棒 / 同色全選預覽用）。
- `js/render.js`：雙色格線、筆刷輪廓（反相填充 + 黑白雙線）、鏡射差異改洋紅斑馬 + 對稱軸虛線（並回報不對稱格數）、裁切八把手（含命中測試）、未標註格黃色斑馬反白、魔棒 / 同色全選的螞蟻線預覽、小圖縮放上限放寬。
- `js/ui.js`：全量重寫。
- `index.html` / `css/style.css`：全量重寫（Design Token 化）。

## 行動版 / 平板（≤900px）

依設計文件附錄 A 的方向補上，**桌面版（≥901px）零改動**：所有樣式只在 `@media (max-width: 900px)` / `(max-width: 560px)` 區塊，JS 以 `matchMedia('(max-width: 900px)')` 或 `pointerType === 'touch'` 守衛；實作前後在 1440×900 / 1280×720 / 1000×720 六種狀態（空、1 圖、2 圖、Tab 收合、裁切、繪圖）量測的版面指紋逐位相同。

- **版面**：畫布佔第一屏大部分（375×812 時 stage 高 712）；底部 56px 工具列 `#dock`（模式切換、目前模式的工具鈕、裁切、⛶ 貼合、⋯、▤）；左欄與右欄改成從底部滑出的**抽屜**（`body.rail-open` / `body.aside-closed`），最高 60%（橫向手機 80%），有遮罩、把手；一次只開一個，開圖片時預設收起；`Esc` 可關。dock 是 `<main>` 最後一個 flex 子元素，像縮圖列一樣把 `#stagewrap` 壓矮，所以 `stageBox()` / `fit()` 不用改。
- **手機（≤560）省空間**：隱藏狀態列、標題列縮放群組與 `?`、`h1`、dock 的 ⛶ 與裁切（裁切走 ⋯ 抽屜的「影像」或 HUD 快選；貼合走 HUD 快選的「⛶ 貼合視窗」或空白處點兩下）；卡片改橫向列；縮圖列縮小。橫向手機（≤480 高）另外隱藏縮圖列與狀態列。
- **觸控目標 ≥44**：dock 鈕 44（手機 40×44）、部件列 44、列內眼睛 / 刪除 / 色塊 44、標題列圖示鈕 44、選單項 44、輸入框字級 16px（iOS 對焦不放大）。部件重排把手在觸控裝置常駐，並設 `touch-action: none`。
- **手勢**（`bindTouch()`，只處理 `pointerType === 'touch'`）：單指畫布上＝畫；單指畫布外空白＝平移；**雙指＝整數倍縮放（以兩指中點為錨）+ 平移**，第二指落下時剛開始的那一筆會整筆撤掉（`abortStroke()`：`undoOnce` + 清掉多出的 redo）；空白處點兩下＝貼合；補上 `pointercancel` 處理。
- 其他：`interactive-widget=resizes-content` + `100dvh` 讓虛擬鍵盤彈出時抽屜跟著上移；`#stagewrap { overflow: clip }` 防止收起的抽屜撐大文件可捲範圍；Toast 在行動版改放標題列下方；`(max-width: 1280px), (max-height: 760px)` 緊湊區塊在手機也會命中，行動版區塊以相同或更高 specificity 覆蓋。
- 已知限制：iOS 忽略 `interactive-widget`（鍵盤彈出時頁面會被推移）；長按沒有做成快選選單（點 HUD 即可）。
