# 匯出格式

在右欄 **匯出** 分頁匯出。單張圖的每種格式都有 **下載** 和 **複製**。

| 格式 | 內容 | 用途 |
|---|---|---|
| **PNG** | 整數倍最近鄰放大：1×、2×、4×、8×、16×、32× | 直接當素材 |
| **SVG** | 同色像素合併成矩形，每色一個 `<path>` | 向量、無限放大 |
| **JSON** | palette + 索引網格（保留既有相容欄位） | 給程式讀 |
| **JS** | 同上，包成 `export const` 模組 | 直接 `import` 進專案 |
| **ZIP** | 所有開著的圖片：每張一個 PNG，64×64 以內的另附 JSON | 一次帶走 |

## PNG

- 每個像素放大成精確的 N×N 方塊，逐格複製，連 alpha 都原樣搬，不做平滑。
- 檔名是 `<名稱>.png`（1×）或 `<名稱>@4x.png` 這樣的格式。
- 放大後超過邊長 16384px 或 4000 萬像素的倍率會被停用。
- **複製** 會把 PNG 放進剪貼簿。瀏覽器不允許的話，改用下載。

## SVG

- 透明像素會略過。同色像素貪婪合併成矩形，同一色的矩形收進同一個 `<path>`。
- 半透明的顏色會加上 `fill-opacity`。
- `viewBox` 以像素格為單位，放大不失真。預設的 `width`、`height` 取整數倍，讓最長邊大約 512px。
- 加上 `shape-rendering="crispEdges"`，相鄰形狀之間才不會出現接縫。

## JSON 與 JS

JSON 和 JS 只支援 64×64 以內的圖，再大資料量就太大了。請先裁切或像素化。

JSON 結構，以 3×2 的圖為例（實際檔案會縮排，每個值一行）：

```json
{
  "name": "sprite",
  "w": 3,
  "h": 2,
  "palette": [null, "#dfe6ee", "#ffb224"],
  "pixels": [[0, 1, 1], [2, 2, 0]],
  "parts": { "names": {}, "colors": {}, "grid": [[0, 0, 0], [0, 0, 0]] }
}
```

JS 模組的資料一樣，只是沒有 `name`：

```js
// sprite — 16x16
export const sprite = {
  w: 16,
  h: 16,
  palette: [null, "#dfe6ee", "#9aa7b4", "#ffb224"],
  pixels: [                       // 每格一個 palette 索引，0 = 透明
    [0, 0, 1, 1, 0, 0],
    // …
  ],
  parts: {
    names: {  },
    colors: {  },
    grid: [
      [0, 0, 0, 0, 0, 0],
      // …
    ],
  },
};
```

- `palette[0]` 一定是 `null`（透明）。其他是 `#rrggbb`，alpha 不是 255 時是 `#rrggbbaa`。顏色依第一次出現的順序排列。
- `pixels` 每一列對應圖片的一列，每格一個 palette 索引。完全透明的像素是 `0`。
- `parts` 是為了相容既有檔案而保留的附加資料。匯入的資料裡有合法的 `parts` 時會原樣帶到匯出；
  否則 `names`、`colors` 是空的，`grid` 全是 `0`。
- JS 匯出的變數名稱取自圖片名稱。`A–Z a–z 0–9 _ $` 以外的字元會換成 `_`；數字開頭或是保留字時，前面會補上 `_`。

## ZIP

- 開兩張以上圖片時才能用，在匯出分頁或 **檔案 → 匯出全部（zip）**。
- 每張圖的 PNG 用目前的倍率。某張圖放大後太大時，那張用 1×。
- 64×64 以內的圖另附 `.json`。
- 檔名是 `pixel-export-YYYY-MM-DD.zip`。檔案只封裝、不壓縮。

## 匯入

用 **貼上 JSON / JS** 卡片、**檔案 → 貼上 JSON / JS…** 或 `Ctrl+V` 貼上文字。匯入支援和匯出一樣的格式，另外還接受：

- **palette 索引**：如上面的 `{ w, h, palette, pixels }`。`pixels` 裡的 `null` 代表透明。
- **hex 字串**：`pixels` 直接放顏色字串（`#rgb`、`#rrggbb` 或 `#rrggbbaa`），不需要 palette。
- **扁平 rgba**：`{ w, h, rgba: [r, g, b, a, r, g, b, a, …] }`，共 `w × h × 4` 個數字。
- 單純的二維陣列會被當成 `pixels`。

細節：

- 有 `pixels` 時可以省略 `w`、`h`，會從陣列推算。每邊 1–512。
- 解析器接受匯出器會產生的語法：裸鍵、單引號、結尾逗號、`//` 與 `/* */` 註解。貼進來的文字永遠不會被當程式執行。
- 圖片名稱依序取自 `name`、`export const <名稱>`、`// <名稱>.png` 註解，都沒有就是 `pasted`。
- `parts.grid` 和圖片尺寸不符時，圖片照樣載入，這份附加資料會略過，並出現提示。
- 把 `.json` 檔拖進畫面沒有作用，拖放只收圖片。請打開檔案、複製文字後貼上。
