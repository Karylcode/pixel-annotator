# 使用方式

## 流程

1. 開啟圖片。
2. 按 **✨ 像素化**，把 AI 圖還原成真正的像素圖。
3. 用繪圖工具修圖、裁切。
4. 到 **匯出** 分頁匯出。

## 畫面

- **標題列**：**檔案 ▾** 選單、**✨ 像素化**、目前的圖片名稱（開兩張以上時點它可以切換）、復原 / 重做 / 歷史、
  縮放，以及開快捷鍵面板的 **？**。
- **左欄**：工具、工具選項、**影像**（裁切、像素化）、**檢視**（顯示原圖、顯示格線）。
- **右欄**：**顏色**、**圖片**、**匯出** 三個分頁。按 **⟨** 或 `Tab` 收合。
- 底部是狀態列，畫布左上角有一個狀態標籤，點它會開快選選單。

## 開啟圖片

- 把 PNG、GIF、BMP、WebP、JPEG 拖到畫面任何地方，一次可以拖好幾張。
- **檔案 → 開啟圖片…**。
- `Ctrl+V` 貼上剪貼簿裡的圖片。
- 要用文字載入像素資料：點 **貼上 JSON / JS** 卡片、用 **檔案 → 貼上 JSON / JS…**，
  或剪貼簿裡有文字時直接按 `Ctrl+V`。`Ctrl+Enter` 載入。格式請看[匯出格式](export-formats.zh-TW.md#匯入)。

圖片上限是邊長 16384px、4000 萬像素。名稱重複時，新圖片的名稱後面會加上 `_`。

## 像素化

按 **✨ 像素化**。視窗一打開就會開始偵測；還沒有結果時，預覽區顯示原圖。
也可以在這裡換一張圖處理：**選擇圖片…**、**貼上圖片**、`Ctrl+V`，或把圖片拖進視窗。換進來的圖會新增成一張圖片。

**① 來源**：顯示圖片名稱、尺寸和顏色數。

**② 格線**：

- **方法**：從十種方法裡選一種。按 **ⓘ** 可以看說明和來源專案。預設是 `pixel-perfecter`，視窗會記住上次的選擇。
  請看[像素化方法](pixelation-methods.zh-TW.md)。
- **目標寬度**（只有 PixelOE、Image-to-Pixel 方法會出現）：輸出的格數寬度，8–512，預設 64。
- 狀態列顯示偵測到的格數、格寬和重建誤差。乾淨的像素圖會被認出來，維持 1:1；
  如果是整數倍放大，就精確還原（除了 `legacy` 以外，會偵測格線的方法都有這個判定）。
- 投票表列出每個偵測器的格數、格寬、信心和狀態。和共識差超過 1 格的偵測器會標 ⚠。
  點某一列就改用那個偵測器的格線；點 **共識／仲裁** 那一列換回來。
- **手動調整格數／格寬／偏移**：格數（每邊 2–512）、格寬、偏移。鎖頭按鈕會鎖住原圖長寬比。
  **自動吸附格線** 只有 `legacy` 能用。**重新偵測** 會重跑一次偵測。

**③ 顏色**：

- **顏色上限**：預設 48，0 = 不減色。最大值是原圖的顏色數，最多 256。
- **減色**：OKLab k-means、中位切割，或不減色。
- **抖色**：無、Floyd–Steinberg、Bayer 2×2、Bayer 4×4、Ordered 8×8、Clustered 4×4、Atkinson，可以調強度。

**④ 清理**：**移除背景**（預設開啟）、**補洞**、**去雜點**、**修鋸齒**、**Alpha 二值**（半透明一律變成全透明或全不透明）。

**進階：取樣與偵測器** 可以換取樣方法、偵測器，以及 **精確仲裁**。改了偵測器，方法就會變成 **自訂組合**。

勾 **比對原圖** 會把原圖疊在結果上，拖下面的拉條左右比對。計算比較久時會出現進度條和 **取消** 鈕。

按 **套用 ✓** 會用結果取代目前這張圖，接著出現可以復原的提示。

## 繪圖與修圖

| 工具 | 鍵 | 功能 |
|---|---|---|
| **繪圖** | `D` | 用前景色塗像素 |
| **滴管** | `I` | 吸取畫布上的顏色 |
| **擦成透明** | `X` | 把像素清成透明 |
| **裁切** | `C` | 只保留框起來的範圍 |

- 筆刷 1–6px。`[`、`]` 縮小 / 放大。
- `Shift+點` 從上一點畫直線。
- `Alt+點` 不用切工具就能吸取顏色。
- **鏡射差異**：把和鏡像不一樣的格子標成洋紅斑馬紋。對稱軸虛線可以直接在畫布上拖，也可以輸入位置
  （可以是 .5，代表落在格線上），或按 **⌖** 自動找最對稱的軸。
- **裁切**：拖八個把手調整大小、拖框內移動、拖框外重新框選。裁切列可以輸入精確的 **X**、**Y**、**寬**、**高**，
  **全選** 選整張圖。`Enter` 套用，`Esc` 取消。

## 顏色

**顏色** 分頁有前景色（色盤加上可編輯的色碼）、上一色和交換鈕、圖片調色盤、最近用色。
圖片調色盤列出目前這張圖用到的顏色。超過 48 色時，挑彼此差異最大的 48 色，不會塞滿一片近似的灰。

## 多圖

可以同時開好幾張圖。在 **圖片** 分頁、縮圖列（開兩張以上才出現，可以收合），或標題列的圖片名稱切換。
關閉圖片用 **檔案 → 關閉圖片…**，或縮圖上的 ×。

## 復原與歷史

- `Ctrl+Z` 復原；`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。
- 按復原鈕旁的 **▾**，或在 ↶ ↷ 上按右鍵，會開歷史面板。點其中一筆可以一次跳多步。
- 每張圖最多保留 60 步，並受記憶體預算限制。
- 裁切、像素化之後，會出現至少 6 秒可以復原的提示。

## 自動保存

圖片和編輯結果存在這個瀏覽器裡，下次打開會自動還原。如果另一個分頁保存了較新的資料，
這個分頁會暫停自動保存，以免互相覆蓋；按 **以這個分頁為準** 可以接手。
細節請看[安裝](installation.zh-TW.md#資料存在哪裡)。

## 快捷鍵

| 鍵 | 功能 | 鍵 | 功能 |
|---|---|---|---|
| `D` `I` `X` | 繪圖 / 滴管 / 擦成透明 | `Ctrl+Z` | 復原 |
| `C` | 裁切（`Enter` 套用 / `Esc` 取消） | `Ctrl+Shift+Z`、`Ctrl+Y` | 重做 |
| `[` `]` | 筆刷縮小 / 放大 | `Alt+點` | 吸取顏色 |
| `+` `-` `0` | 放大 / 縮小 / 貼合視窗 | `Shift+點` | 從上一點畫直線 |
| `Space` 拖曳 | 平移畫布 | `Ctrl+滾輪` | 以游標為中心縮放 |
| `Tab` | 收合 / 展開右欄（焦點不在控制項上時） | `Ctrl+V` | 貼上圖片 / JSON |
| `?` | 快捷鍵面板 | `Esc` | 取消、離開輸入框 |

## 滑鼠與觸控

- 按右鍵叫出快選選單（工具、前景色、裁切、像素化、貼合視窗）。拖曳右鍵或中鍵是平移。
- 螢幕寬度 900px 以下時，底部工具列放工具、貼合視窗、**⋯**（工具選項、影像、檢視）和 **▤**（顏色、圖片、匯出），
  面板以抽屜方式打開。
- 觸控螢幕：單指在空白處拖曳是平移，雙指縮放兼平移，在空白處點兩下會貼合視窗。主要的觸控目標都至少 44px。
- 淺色 / 深色主題跟隨系統設定。控制項可以用鍵盤操作，也有 ARIA 標記。
