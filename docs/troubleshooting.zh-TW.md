# 疑難排解

## 像素化

- **格數偵測錯了**：換一種方法試試，每種偵測方式不同。在投票表點某個偵測器那一列，改用它的格線；
  或在 **手動調整格數／格寬／偏移** 自己設定格數、格寬、偏移。請看[像素化方法](pixelation-methods.zh-TW.md)。
- **出現「這已經是原生像素圖」或「將以 1:1 處理」**：這張圖是乾淨的像素圖，或找不到格線週期，所以維持原尺寸。
  仍然可以減色、去背、抖色。如果它其實是放大過的圖，請手動設定格線，或改用 `legacy`（它不做這項判定）。
- **小細節或顏色不見了**：調高 **顏色上限**，或設成 0 不減色。
- **移除背景吃掉了角色的一部分，或留下鑲邊**：關掉 **移除背景**，比較看看結果。
- **自動吸附格線是灰的**：它只在 `legacy` 方法可用。其他方法會自己算格線，吸附會蓋掉它們的結果。
- **像素化很慢**：`pixel-art-fixer-full` 是最慢的方法，可以按 **取消** 換一種。整數倍放大的圖用 `perfectPixel` 最快。
  用 `file://` 開時，像素化跑在主執行緒；請改用線上版或本機伺服器（[安裝](installation.zh-TW.md#在本機執行)）。
- **像素化視窗出現「剪貼簿裡沒有圖片」**：先複製一張圖，或改用 **選擇圖片…**。

## 開啟與匯入

- **出現「圖片太大」**：上限是邊長 16384px、4000 萬像素。請先縮小。
- **出現「無法取得圖片尺寸（向量圖請先轉成 PNG）」**：瀏覽器取不到尺寸，向量圖常會這樣。請先轉成 PNG。
- **把 `.json` 檔拖進來沒反應**：拖放只收圖片。打開檔案、複製文字，再用 `Ctrl+V` 或 **檔案 → 貼上 JSON / JS…** 貼上。
- **貼上視窗出現錯誤**：訊息會說明問題，語法錯誤會標出「第 N 行附近」。請對照[匯出格式](export-formats.zh-TW.md#匯入)
  檢查結構。每邊必須是 1–512，`pixels` 是數字索引時需要 `palette`。
- **出現「附加資料…不符，已略過」**：圖片已經載入，但 `parts` 資料的尺寸不對，所以略過。

## 匯出

- **JSON、JS 不能用（「圖片大於 64×64」）**：只支援 64×64 以內的圖。先裁切或像素化。
- **某個 PNG 倍率是灰的（「放大後超過記憶體上限」）**：那個倍率會超過邊長 16384px 或 4000 萬像素。選小一點的倍率。
- **ZIP 不能用**：要開兩張以上圖片。
- **出現「複製圖片失敗」**：瀏覽器不允許把圖片寫進剪貼簿。改用下載 PNG。
- **出現「PNG 編碼失敗（記憶體不足），未放進 zip」**：瀏覽器記憶體不夠處理某些圖。把那些圖單獨匯出，或用小一點的倍率。

## 保存

- **出現「瀏覽器儲存空間不足」**：之後的變更不會自動保存。先下載 JSON 備份，或關閉用不到的圖片。
- **出現「未能保存到瀏覽器」**：請下載 JSON 備份。
- **出現「另一個分頁保存了較新的資料」**：這個分頁已暫停自動保存，以免兩個分頁互相覆蓋。
  按 **以這個分頁為準** 接手，或回到另一個分頁繼續做。
- **出現「已還原 … 保存的版本」**：之前有一次因為儲存空間不足沒存成功，那個時間之後的變更沒有保存。
- **出現「上次保存的資料已損毀」**：資料無法還原，已經清除。
- **出現「有 N 張圖無法還原」**：保存的資料裡少了這幾張圖。請重新開啟。
- **想從頭開始**：**檔案 → 清除瀏覽器裡的保存資料…** 會刪掉保存的資料，目前開著的圖片不受影響。

## 畫面
